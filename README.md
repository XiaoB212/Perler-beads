# 拼豆工作室 · Perler Studio

一个纯前端的拼豆（Perler Beads）图纸工具：画图纸、把照片转成图纸、算用量、算钱、勾进度、导出打印。
**免登录、不联网、所有数据只存在你自己的浏览器里。**

> 市面上的拼豆工具大多只解决「生成图纸」。真正拼起来时会遇到的问题是：拼到哪了？还差多少颗？要花多少钱？几块板？怎么打印到 A4？—— 这个项目补的就是这一段。

## 功能

### 画
- 新建任意尺寸画布（14 / 29 / 48 格标准板，或自定义到 300×300）
- 画笔、橡皮、油漆桶、直线、矩形、椭圆、吸管、平移
- 画笔粗细 1–16、形状可填充或描边
- X / Y 双向对称绘制
- 60 步撤销重做，`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`
- 滚轮平移、`Ctrl/⌘+滚轮` 以指针为中心缩放、`空格` 拖动画布
- 网格、坐标标尺、豆孔、拼豆板分界线、未拼变暗，全部可开关
- 300×300（9 万格）大画布也流畅：绘制按颜色合批、只重绘视口内的格子

### 以图生图
- 拖一张图片进窗口即可开始（照片、插画、截图都行）
- 手上已有别人的图纸截图也一样能用：把图片拖进来，它会自动套色成可编辑的色块图纸，之后每个格子都能改
- 目标宽度可调，高度按比例自动计算
- 最多色数、抖动强度、采样方式（点采样 / 均值）、亮度 / 对比度 / 饱和度
- 白底自动透明，白点阈值可调
- 颜色在 **CIEDE2000** 色差空间里做 k-means 聚类 + Floyd–Steinberg 误差扩散，比直接取 RGB 最近色细腻得多
- 可直接套用当前图纸色板，或指定品牌色板

### 色号管理
- 内置 **9 套真实品牌色卡，共 2449 色**：MARD 291、COCO 291、漫漫 278、咪小窝 290、盼盼 289、Artkal 418 / 197 / 221、优肯 174，另有不依赖品牌的基础 32 色
- 色卡数据全部**随站点打包在本地**，运行时零联网；色号、HEX 都来自官方色卡实测，不是估算出来的近似色
- 色板按色号前缀自动分组（A / B / C…、CT / MA–MM…），可只看某一族
- 任意改色号、色名、HEX
- 自定义增删颜色；删除时自动清理画布上的引用并重映射索引
- 一键换整套色板，旧色按最近色自动映射到新色板
- 右侧色板底部「从品牌色板添加」：直接在 9 套官方色卡里按色号或色名搜，点一下就加进当前图纸，不用先建自定义色
- 2449 色不会一次性铺满页面：默认先出 96 个，滚到底部按需继续显示

### 用量与成本
- 实时统计总颗数、已拼、剩余、色数
- 按色号明细列出每种颜色需要多少颗、还差多少颗
- **成本估算**：默认单价（元 / 千颗）+ 每个色号单独定价 → 材料费合计、未拼部分花费
- **库存管理**：填每个色号的已有库存 → 自动算出「需补货颗数」和「补货花费」，以及库存抵掉的钱
- 分板数量：按拼豆板格数自动算需要几块板

### 进度
- 进度模式下一键把已拼的格子打勾，画布上显示对勾、未拼的自动变暗
- 一键全拼 / 重置进度
- 进度随工程一起保存和导出
- 首次打开的内置示例图纸已经把最下面三行标记成「已拼」，打开「进度模式」就能接着往下勾

### 导出
| 格式 | 用途 |
| --- | --- |
| PNG | 分享、发群里，可画出拼豆板框与板号 |
| SVG | 矢量图，无限放大不失真，可进 Illustrator / Figma |
| PDF | **整张图纸缩放进一张 A4**，带坐标标尺、5 格加粗线、50 mm 校准尺与「按 100% 打印」提示 |
| CSV | 用量清单（含单价、金额、库存、需补货），可直接进 Excel |
| `.perler.json` | 工程文件，含画布 + 色板 + 进度，可完整恢复 |

PDF 有三种排版，都在导出面板里实时预览真实纸张、可翻页：

- **整张一页**：整张图纸自动缩放到一页内，看全局、存档、发人；
- **一板一页**：按实体拼豆板尺寸（10 / 14 / 15 / 20 / 28 / 29 / 48 格）切分，一块板一页、按真实比例放大，四边带拼装对位标记，打印出来可以直接垫在板子上拼；
- **分块**：按每页格数自由切分。

大图可以先看「整张一页」确认全局，再切「一板一页」逐块打印。PNG / SVG 同样可选是否画出板框与板号。

### 本地
- 所有图纸自动存在浏览器 `localStorage`，2.6 秒防抖自动保存，关掉浏览器再打开还在
- 「我的图纸」里可切换、重命名、删除
- 无账号、无后端、无埋点、无网络请求（构建产物完全静态）

### 界面
- **亮色 / 暗色双主题**，也可以「跟随系统」；切换即时生效，并记住你的选择
- 画布本身也跟着主题走：底板、网格、豆孔、标尺、对勾都有各自的亮暗配色，不是简单反色
- 桌面 / 平板 / 手机三端布局，手机上是底部工具条 + 抽屉面板 + 双指缩放
- 每颗豆子上可以叠印色号（放大到 120% 以上才显示，避免糊成一团）

## 本地运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 产物在 dist/
npm run preview    # 预览构建产物
npm run typecheck  # 只跑类型检查
```

需要 Node 18+。

## 部署到 GitHub Pages

仓库已经带了 workflow（`.github/workflows/deploy.yml`），推上去就能用。

1. 在 GitHub 新建一个空仓库（不要勾 README / .gitignore），然后：

   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

2. 打开仓库 **Settings → Pages**，把 **Source** 设成 **GitHub Actions**。

3. 等 Actions 跑完（约 1 分钟），访问 `https://<你的用户名>.github.io/<仓库名>/`。

`vite.config.ts` 里 `base: './'` 用的是相对路径，所以放在仓库子路径下也能正常加载，不用改配置。workflow 里会把 `index.html` 复制成 `404.html`，直接访问深链接也不会 404。

想部署到自己的服务器：把 `dist/` 整个目录丢到任意静态服务器即可。

## 技术栈

- React 18 + TypeScript（strict）
- Vite 5，代码分包：jsPDF 单独 chunk，首屏不背 PDF 的体积
- Zustand 做编辑器状态，`Uint16Array` / `Uint8Array` 存像素与进度，60 步快照历史
- 颜色科学：sRGB → CIELAB、CIEDE2000 色差
- 渲染：双 canvas（内容层 + 交互覆盖层），`ResizeObserver` 自适应
- 无 UI 框架，手写 CSS 设计系统，一套语义变量驱动亮 / 暗两套主题

```
src/
  core/        纯逻辑，不依赖 React
    types.ts        数据模型
    palette.ts      色卡入口与别名解析
    palette-data.ts 9 套真实色卡数据（自动生成，勿手改）
    color.ts        色彩空间与色差
    quantize.ts     图像 → 图纸
    rle.ts          像素压缩
    storage.ts      localStorage 持久化
    export.ts       PNG / SVG / PDF / CSV / 工程文件
    cost.ts         成本与库存
    theme.ts        亮暗主题与画布配色
    demo.ts         首次访问的示例图纸
    store.ts        编辑器状态与历史
  components/  画布与各面板
  styles/      设计系统 + 布局 + 画布 + 面板
```

## 色号数据来源

色卡数据来自开源项目 **[pindou-color-data](https://github.com/HansBug/pindou-color-data)**（作者 HansBug，MIT 许可，Copyright © 2026 HansBug），覆盖 MARD、COCO、漫漫、咪小窝、盼盼、Artkal、优肯等主流品牌的官方色号与实测 HEX。

- 构建时由 `scripts/gen-palettes.mjs` 抓取并生成为 `src/core/palette-data.ts`，**编译进产物，运行时不发任何网络请求**
- 数据本身不含中文色名，中文色名由脚本按 HSL 色相 + LAB 明度/彩度自动生成，仅供辨认，不代表厂商官方命名
- 色卡版权归各厂商所有；本项目对色卡数据的使用遵循上游 MIT 许可，完整声明见 [NOTICE](./NOTICE)
- 若要更新色卡：`node scripts/gen-palettes.mjs`（需要联网，仅开发时用）
